Use the dev server, not the file

This page is the browser harness for the AI Manager webview. It loads the bundle and its fixtures over HTTP, which a file:// page cannot do — so it renders nothing when opened directly from disk.

From extensions/ai-manager:

npm run dev  →  http://localhost:3731/

  • ?theme=light — light palette
  • ?scenario=empty — a brand-new repository with nothing selected
